
# Subscription Data - Exploratory Data Analysis (EDA)

## Project Overview
This project focuses on Exploratory Data Analysis (EDA) of subscription data using Python. The main objective is to understand customer subscription patterns, analyze customer behavior, and identify useful business insights.

## Objectives
- Understand subscription data.
- Analyze customer demographics and subscription plans.
- Identify patterns in customer behavior.
- Handle missing values and duplicate records.
- Generate meaningful insights from the dataset.

## Tools & Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib

## Dataset
The dataset contains subscription-related information such as:
- Customer ID
- Gender
- Age
- City
- Subscription date
- Plan type
- Monthly fee
- Tenure months
- Support tickets
- Average session time
- Discount percentage

## Project Steps
1. Import required Python libraries.
2. Load the dataset.
3. Understand the data structure.
4. Check missing values and duplicates.
5. Perform data cleaning.
6. Conduct Exploratory Data Analysis.
7. Analyze trends and patterns.
8. Generate business insights.

## Key Learnings
- Improved Python data analysis skills.
- Learned data cleaning techniques.
- Practiced exploratory data analysis.
- Understood customer subscription patterns.

## Project Files
- subscription_data_project.ipynb – Jupyter Notebook containing the complete analysis.
- subscription_data.csv – Dataset used for analysis.

## Conclusion
This project helped me understand subscription data through Python-based analysis and identify meaningful patterns that can support business decision-making.
